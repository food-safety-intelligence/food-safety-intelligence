1"""Mitigation analysis — ANALYSIS ONLY, the model is never changed here. 

2 

3If the audit found an equalized-odds gap on some axis, the cheapest post-hoc fix 

4is a per-group decision threshold: pick, for each group, the score cutoff that 

5gives every group the same recall (miss rate), and price what that costs in extra 

6inspections and precision. This quantifies the fairness/cost trade-off at the 

7operating point without touching the model or its features. 

8 

9Nothing here writes a model or a served artifact. It edges toward the 

10out-of-scope "reweighting" line, so any decision to actually adopt per-group 

11thresholds is a product/scope call (Jun), not something this module enacts. 

12"""

24 column: str, 

25 *,

30 """Per-group score threshold that equalizes recall, and the cost of adopting it. 

31 

32 Baseline is the single deployed cutoff (the lowest score still in 

33 ``flagged_tiers``). ``target_recall`` defaults to the pooled recall at that 

34 cutoff, so the analysis answers: "give every group the pooled miss rate — what 

35 threshold does each need, and how many extra inspections does that add?" 

36 

37 Returns one row per odds-reliable group with the baseline and adjusted 

38 threshold, flag rate, FPR and recall, and the change in flagged count. The 

39 aggregate extra-inspection count is attached as ``df.attrs['total_delta_flags']``. 

40 """ 

41 df = frame[frame[column].notna()].copy() 

42 flagged0 = fairness.flagged_mask(df["risk_tier"], flagged_tiers).to_numpy() 

43 scores = df["y_score"].to_numpy() 

44 y = df["y_true"].to_numpy()

49 target = pooled_recall if target_recall is None else target_recall 

50 

51 rows = [] 

52 total_delta = 0

60 # Group cutoff that lets exactly `target` of positives through.

62 adj_flag = gs >= tau_g 

63 delta = int(adj_flag.sum() - base_flag.sum()) 

64 total_delta += delta 

65 rows.append(

68 "n": int(len(g)), 

69 "positives": int(pos.sum()),

74 "target_recall": round(float(target), 4), 

75 "adj_threshold": round(tau_g, 4), 

76 "adj_flag_rate": round(float(adj_flag.mean()), 4), 

77 "adj_recall": round(float(adj_flag[pos].mean()), 4),
