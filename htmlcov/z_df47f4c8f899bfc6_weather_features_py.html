1"""Citywide daily-weather features, joined on date (NOAA GHCN-Daily, O'Hare). 

2 

3Unlike every other ``prior_*`` module, this one has no ``license_id`` grouping: 

4weather is a single citywide signal shared by every restaurant inspected on the 

5same day, so the rolling windows are computed once on the daily weather series 

6(``foodsafety.io.noaa.fetch_noaa_ghcnd``) and then joined onto the anchor table 

7by date. 

8 

9Motivation (``docs/data_dictionary.md`` § NOAA weather): heat stresses 

10refrigeration and drives pest activity; freeze stress affects plumbing/water 

11systems. `temporal_month` / `temporal_quarter` already capture coarse 

12seasonality — these features test whether actual daily weather carries 

13*incremental* signal over that proxy, per the 2014 Chicago forecasting paper's 

14use of a 3-day rolling high temperature. 

15 

16Leak guard: every column is ``.shift(1)``-ed on the daily series before the 

17join, so a row anchored on date D only sees weather strictly BEFORE D — the 

18same "strictly before" discipline as the license-level ``prior_*`` columns in 

19``inspection_features.py``, just without a groupby (there's only one weather 

20series, not one per license). 

21""" 

22 

23from __future__ import annotations 

24 

25import pandas as pd 

26 

27# Thresholds match the imperial-unit framing used when this feature was scoped 

28# (90F / 32F), converted to the Celsius units NOAA's GHCN-Daily reports in. 

29_HEAT_THRESHOLD_C = 32.2 # 90 degF 

30_FREEZE_THRESHOLD_C = 0.0 # 32 degF 

31 

32 

33def add_weather_features( 

34 df: pd.DataFrame, 

35 weather: pd.DataFrame, 

36 *, 

37 date_col: str = "inspection_date", 

38) -> pd.DataFrame: 

39 """Append citywide weather features, joined onto ``df`` by ``date_col``. 

40 

41 Args: 

42 df: anchor table with a date column (e.g. ``inspections_labeled``). 

43 weather: output of ``foodsafety.io.noaa.fetch_noaa_ghcnd`` — one row 

44 per date with ``tmax_c``, ``tmin_c``, ``precip_mm``, ``snow_mm``. 

45 date_col: column in ``df`` to join on. 

46 

47 Features added (every one describes weather STRICTLY BEFORE ``date_col``): 

48 prior_tmax_3d_avg float — 3-day rolling mean daily max temp, degC 

49 prior_tmin_3d_avg float — 3-day rolling mean daily min temp, degC 

50 prior_precip_7d_sum float — 7-day rolling total precipitation, mm 

51 prior_heat_days_30d float — count of days TMAX > 90 degF in trailing 30d 

52 prior_freeze_days_30d float — count of days TMIN < 32 degF in trailing 30d 

53 

54 Rows whose date falls before the weather series' first available date (or 

55 in a gap the station didn't report) get NaN — tree models handle NaN 

56 natively; a LogReg pipeline imputes (see ``build_baseline_pipeline``). 

57 Returns a new DataFrame; does not mutate either input. 

58 """ 

59 out = df.copy() 

60 out[date_col] = pd.to_datetime(out[date_col]) 

61 

62 # Reindex to a continuous daily calendar so the rolling windows count 

63 # actual elapsed days rather than "however many station readings exist" — 

64 # a station gap shouldn't silently shrink a 30-day window to 30 readings 

65 # spanning 40 calendar days. 

66 w = weather.sort_values("date").set_index("date") 

67 full_idx = pd.date_range(w.index.min(), w.index.max(), freq="D") 

68 w = w.reindex(full_idx) 

69 w.index.name = "date" 

70 

71 daily = pd.DataFrame( 

72 { 

73 "prior_tmax_3d_avg": w["tmax_c"].rolling(3, min_periods=1).mean(), 

74 "prior_tmin_3d_avg": w["tmin_c"].rolling(3, min_periods=1).mean(), 

75 "prior_precip_7d_sum": w["precip_mm"].rolling(7, min_periods=1).sum(), 

76 "prior_heat_days_30d": (w["tmax_c"] > _HEAT_THRESHOLD_C) 

77 .rolling(30, min_periods=1) 

78 .sum(), 

79 "prior_freeze_days_30d": (w["tmin_c"] < _FREEZE_THRESHOLD_C) 

80 .rolling(30, min_periods=1) 

81 .sum(), 

82 } 

83 ) 

84 # The leak guard: shift every column by one calendar day so date D's row 

85 # carries weather computed over [D-window, D-1], never D itself. 

86 daily = daily.shift(1) 

87 

88 out = out.merge(daily, left_on=date_col, right_index=True, how="left") 

89 for col in ( 

90 "prior_tmax_3d_avg", 

91 "prior_tmin_3d_avg", 

92 "prior_precip_7d_sum", 

93 "prior_heat_days_30d", 

94 "prior_freeze_days_30d", 

95 ): 

96 out[col] = out[col].astype("float64") 

97 

98 return out
