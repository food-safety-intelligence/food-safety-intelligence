1"""Audit configuration — grouping axes, ACS variable registry, tolerance bands. 

2 

3Single source of truth for *what* the fairness audit measures and *what counts as 

4a flag*. The audit engine (``fairness.py``) and the census join (``census.py``) 

5read these registries so the same rules apply to every city. 

6 

7Design notes: 

8 * Continuous demographic variables are bucketed into **within-city quantiles** 

9 so "low-income tract" is relative to each city and comparable across the three. 

10 * Exact ACS 5-year variable codes are NOT hardcoded here — they are resolved and 

11 validated against the Census data dictionary in ``census.py``. This registry 

12 carries the concept + table family + how to bucket it, which is stable; the 

13 numeric codes are an implementation detail that changes between ACS vintages. 

14""" 

15

20# --------------------------------------------------------------------------- # 

21# Operating point: what "flagged" means for FPR / FNR / statistical parity. 

22# The models emit a continuous risk plus a discretised tier (Low / Moderate / 

23# Elevated / High, from serve.predict_batch.assign_risk_tiers). We audit the 

24# disparity users actually experience, so "flagged" = the deployed High tier. 

25# Elevated+High is carried as a secondary cut (a wider worklist). 

26# --------------------------------------------------------------------------- # 

27FLAGGED_TIERS_PRIMARY: frozenset[str] = frozenset({"High"}) 

28FLAGGED_TIERS_SECONDARY: frozenset[str] = frozenset({"Elevated", "High"}) 

29 

30# Top-K cross-check: a threshold-free view aligned with the existing 

31# precision@k / recall@k convention in models.evaluate.group_performance_audit. 

32TOP_K_FRAC: float = 0.10 

33 

34# --------------------------------------------------------------------------- # 

35# Noise floors. Small / low-prevalence groups swing on base rate, not bias 

36# (the recurring lesson — decision 0005). A group is only *audited* above these 

37# floors, and a gap is only called a finding when its bootstrap CI clears the 

38# tolerance band below. 

39# --------------------------------------------------------------------------- # 

40MIN_GROUP_N: int = 50 

41MIN_GROUP_POSITIVES: int = 50 # treat sub-~50-positive groups as noise 

42N_BOOTSTRAP: int = 1000 # seeded by config.RANDOM_STATE in fairness.py 

43 

44# --------------------------------------------------------------------------- # 

45# Tolerance bands — the line between "gap" and "finding". 

46# --------------------------------------------------------------------------- # 

47# Statistical parity: the four-fifths rule. A group's flag rate below 80% (or the 

48# most-flagged group's rate above 125%) of the reference is a disparate-impact flag. 

49DISPARATE_IMPACT_RATIO_MIN: float = 0.80 

50# Equalized odds: absolute FPR / FNR gap (max - min across audited groups) that we 

51# treat as material once the CI excludes it. 

52FPR_GAP_MAX: float = 0.10 

53FNR_GAP_MAX: float = 0.10 

54# Calibration: absolute gap in expected calibration error across groups. 

55ECE_GAP_MAX: float = 0.05 

56
