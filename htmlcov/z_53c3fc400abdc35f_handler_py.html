1""" 

2Lambda handler: food_safety_info 

3-------------------------------- 

4Answers GENERAL food-safety and foodborne-illness questions (what a pathogen is, 

5how common illness is, safe cooking temperatures, who is most at risk, how to 

6prevent it) with short, vetted facts AND a citation to an authoritative public 

7health source the user can click through to. 

8 

9This is the educational counterpart to the restaurant-risk tools. It is NOT about 

10any specific establishment's score — it gives general public-health information 

11and verifiable links. The "local" topic is city-aware: it surfaces the ACTIVE 

12CITY's health department + inspection portal (Chicago, NYC, or LA). 

13 

14GROUNDING & SOURCING POSTURE — read before changing this file: 

15 * Every fact in this file is a short paraphrase of an AUTHORITATIVE public 

16 health source, and every entry ships the source link it came from. The agent 

17 relays these vetted facts and cites the link — it must not invent statistics 

18 of its own. This keeps the citation TRUE: the number the user reads and the 

19 page the link opens are the same source. 

20 * Sources are restricted to a curated ALLOWED_DOMAINS allow-list (US federal 

21 public-health agencies, the WHO, NIH MedlinePlus, a recognised food-safety 

22 nonprofit, and the covered cities' local public health: Chicago / Illinois / 

23 Cook County + the Chicago Data Portal, NYC Health, and LA County Public 

24 Health). No news outlets, no blogs, no open web search — those are not 

25 authoritative for disease statistics and their links rot or paywall. 

26 * Links are stable landing pages, not search URLs. The eval harness 

27 (agents/eval/run_eval.py --links) resolves every URL so dead links are caught 

28 before they reach a user; the always-on gate checks each URL is on the 

29 allow-list. If you add or change a source, run the link check. 

30 * This tool gives information, never medical advice. Personal "what should I 

31 eat / is it safe for me" questions are steered to a professional — that 

32 boundary lives in the system prompt and the Bedrock guardrail, not here. 

33"""

428 """Pick topic keys from an explicit list or by matching the query text. 

429 

430 Explicit `topics` win when any are valid. Otherwise scan the query for known 

431 synonyms (longest match first so "e. coli" beats a stray "coli"). Falls back 

432 to the overview + prevention default when nothing matches. 

433 """ 

434 if raw: 

435 if isinstance(raw, str): 435 ↛ 436line 435 didn't jump to line 436 because the condition on line 435 was never true

436 raw = [raw] 

437 keep = [ 

438 t.strip().lower() 

439 for t in raw 

440 if t.strip().lower() in _TOPICS or t.strip().lower() == "local" 

441 ]

443 return keep[:_MAX_TOPICS]

446 matched: list[str] = []

448 if phrase in text:

476def is_allowed_url(url: str) -> bool: 

477 """True if the URL is https and its host is on (or under) ALLOWED_DOMAINS.""" 

478 parsed = urlparse(url) 

479 if parsed.scheme != "https" or not parsed.hostname: 

480 return False 

481 host = parsed.hostname.lower() 

482 return any(host == d or host.endswith("." + d) for d in ALLOWED_DOMAINS)
