Data and EDA

Four public Chicago datasets feed the model

Sources
  • Food Inspections · 310,882 rows · labels + most prior-history features.
  • 311 Service Requests · ~3.2 M · 8 food-relevant types, BallTree-prepped.
  • Business Licenses (current) · 48,535 active food licenses.
  • Business Licenses (historical) · ~640 K rows · license age + activity.
Target and key EDA numbers
  • Label: y_fail_or_critical_next_180d. Forward 180-day window, right-exclusive of the anchor.
  • Positive rate on hold-out 10.5%. Imbalanced but not extreme.
  • 2019-01-01 burn-in cutoff. July 2018 procedure change makes pre/post labels non-comparable.
  • 26 features after Phase 5 ablation. 11 numeric, 3 categorical, 12 keyword flags.

The label is a measurable proxy. It does not capture food-safety risk itself, only the patterns that historically precede a failed inspection.

Feature selection · evidence 1

Feature correlation matrix

  • Historical block. prior_inspections, prior_fails, prior_priority_violations, and license_n_history_rows move together. Dark red cluster top-left.
  • Operational pairings. flag_kw_no_soap + flag_kw_no_paper_towels (handwashing failures come in pairs). flag_kw_rodent + flag_kw_pest. flag_kw_temperature + flag_kw_cooling.
  • Justifies tree models. Linear models would be destabilized by these collinear blocks. XGBoost and Random Forests handle them without inflating variance.

Where features cluster, we keep the count features and drop the ratio features. Tree models reconstruct ratios from numerator and denominator anyway.

Feature selection · evidence 2

XGBoost gain vs Pearson correlation

XGBoost is the diagnostic here, not the production model. We fit it on the same 26 features to surface importance that linear correlation misses. The chart compares each feature's normalized XGBoost gain against its absolute Pearson correlation with the label.

  • Keyword flags dominate gain. flag_kw_pest tops at normalized gain 1.0. flag_kw_handwash_sink follows at ~0.7.
  • Gain >> linear correlation. flag_kw_pest has only ~0.2 Pearson correlation with the label but the highest gain of any feature. The relationship is non-linear or interactive (e.g. pest flag combined with another signal).
  • Tenure features are weak. license_age_days and temporal_quarter sit near zero on both axes. Operational signal beats "how long the place has been open."

These insights guide which features the production logistic regression keeps, and they shape what XGBoost would gain from once we tune it as a candidate production model after NLP layer C.
