Three mockup directions

Each direction is a complete, demoable HTML pair — Home + Restaurant Detail — sharing one design system. Open each and click through to the detail page. Pick the one that should be ported to Next.js + shadcn/ui in the real build.

  • Direction 01

    Civic Investigative

    Newsprint editorial. Fraunces serif headlines + Spectral body. Tabular numbers. Generous rule lines. Drop-cap weight. Reads like a Bloomberg CityLab feature or a Pudding long-form. Best if the team wants the project to feel like investigative civic journalism.

  • Direction 02

    Clinical Quiet

    Warm-clean patient portal. Manrope sans + Instrument Serif italic accents. Sage, slate, peach, terracotta — risk colors that don't shout. Soft shadows, rounded forms, generous whitespace. Best if the priority is not alarming the user, particularly for immunocompromised diners.

  • Direction 03

    Chicago Pulse

    Bold civic-tech. Midnight navy with cream cards floating, topographic line texture. Newsreader italic display + IBM Plex Sans + IBM Plex Mono for data. Animated pulse on the high-risk pins. Best if the project should feel like a modern operations dashboard the city's data team would actually use.
