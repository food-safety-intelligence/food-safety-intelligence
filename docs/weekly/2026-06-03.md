## What changed this session

### Modeling
- **Calibration: isotonic → sigmoid (Platt).** Isotonic was a step function
  that quantised 23,513 restaurants to only 60 distinct probabilities, so
  the UI's top-200 list showed many duplicate `0.48`s. Sigmoid is continuous.
  - Script: [scripts/retrain_baseline_sigmoid.py](../../scripts/retrain_baseline_sigmoid.py)
  - Run: `PYTHONPATH=src /Users/jun/anaconda3/bin/python scripts/retrain_baseline_sigmoid.py`
  - Model: `data/models/baseline_sigmoid_20260603.joblib`
  - Metadata: `data/models/baseline_sigmoid_20260603_metadata.json`
- **Held-out metrics (test n=13,070):** PR-AUC 0.267, ROC-AUC 0.774,
  Precision@5% 0.353, top-decile lift 3.4×. Comparable to the isotonic run
  (PR-AUC 0.252) — within noise.
- **Tier distribution:** Low 20% · Moderate 68% · Elevated 11% · High 1.4%
  (318 restaurants).

### Data pipeline
- **Inspection history exporter.** Previous `scores.json` didn't include
  per-restaurant inspection records → web app showed "0 inspections" on
  every detail page. New sidecar JSON fixes that.
  - Script: [scripts/export_inspection_history.py](../../scripts/export_inspection_history.py)
  - Output: `app/public/data/inspection_history.json` (~45 MB, 306,749
    events across 48,535 restaurants; capped at the 30 most-recent events
    per license — p99 of the distribution, covers 99.6% of events).
- **scores.json schema:** bumped to `0.3.0`; `model_version` is now
  `baseline_logreg_sigmoid`.

### Web app
- **Map-first home.** Full-bleed CartoDB Voyager tiles + floating search +
  tier filter chips + side list. No API key. Pin density is zoom-aware:
  caps at 80 pins below zoom 11, 250 below 12.5, 600 below 13.5, then
  viewport-clipped up to 1,500 above. Map gets the FULL 23k-restaurant
  pin set (minimal fields, ~3 MB RSC payload); side list still uses the
  top-200 by score.
- **Custom teardrop markers.** SVG with white inner dot, drop shadow, and
  a hover/select halo + 1.25× scale.
- **Detail page redesign.**
  - `ArcGauge` SVG (270°) replaces the gradient bar.
  - `TrendChart` SVG renders the 90-day trajectory from the linear slope.
    When slope is null (most restaurants — < 2 inspections in last 90d), we
    now show plain text instead of a misleading dashed line.
  - `DriverList` icons: lucide-react topic icons per feature family
    (`Bug` for pest, `Thermometer` for temp, `Hand` for handwash, etc.),
    polarised terra/sage by SHAP sign.

### Code quality
- TypeScript strict typecheck clean.
- One pre-existing type bug fixed in `app/src/lib/scores.ts`
  (`trend_ci_low/high` declared twice).

## One learning

Isotonic calibration on a tree-shaped feature set produces an aggressive
step function — verify uniqueness of the calibrated output before assuming
the model is "broken" when many predictions look identical. Sigmoid was a
one-line swap that gave continuous probabilities with the same downstream
metrics.
