## One learning

A single-split improvement can be a lucky window. Run 3 showed a +0.007 PR-AUC
morsel on one split that expanding-window cross-validation revealed was −0.002 on
average — a textbook false positive. CV effort should scale with how marginal and
how high-blast-radius the change is; clear wins and clear flats don't need it, but
marginal-adopt candidates do.
